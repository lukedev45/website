This site is a static Astro project. It started from the official blog template
and was reworked into a minimalist single-column design.

Highlights:

- Markdown/MDX posts validated by a typed content schema.
- A projects collection (this page is one entry).
- Tag pages, an RSS feed, and a sitemap.
- Dark/light mode with no flash on load.
- Zero client JavaScript beyond the theme toggle.

The source is on GitHub — see the link above.
